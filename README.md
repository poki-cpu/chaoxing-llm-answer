# 超星学习通 / 知到智慧树 网课小助手（大模型答题版）

在公开的「超星学习通｜知到智慧树 网课小助手」（作者 isMobile，MIT 许可）基础上修改而来，主要改动：

- 🤖 **接入大模型答题**：填入任意 OpenAI 兼容接口（DeepSeek、通义千问、Kimi、智谱、硅基流动等），题目直接交给大模型作答，不再依赖题库。
- ⏱ **答题间隔可配置**：默认每道题随机等待 5~8 秒。
- 🚫 **不内置题库、不推荐任何题库服务商**：已去掉原版的公告模块与题库推广内容，也没有任何题库链接。
- 🐛 **失败原因可见**：作答失败时日志会直接写明原因（HTTP 状态码、接口地址、超时、格式解析失败等），并带有大模型连接自检日志。
- ✍️ **答案格式明确**：选择题直接标出该选 A、B、C、D 里的哪一个（如 B. 上海），判断题给出「对」或「错」，日志和「题目」页都能一眼看清。
- 🖱 面板支持滚轮滚动，设置项带说明文字。

> 📖 **第一次用、没用过脚本管理器？照着这份从零教程做：[使用教程](./使用教程.md)**

## 安装

1. 浏览器安装脚本管理器：[脚本猫](https://docs.scriptcat.org/) 或 Tampermonkey。
2. 打开 [`chaoxing-llm-answer.user.js`](./chaoxing-llm-answer.user.js)，点 `Raw`，按提示安装；或者直接打开这条 raw 链接自动弹出安装页：https://raw.githubusercontent.com/poki-cpu/chaoxing-llm-answer/main/chaoxing-llm-answer.user.js
3. 进入学习通 / 知到智慧树的答题页面，页面右上角会出现脚本面板。

## 使用

### 用大模型答题（推荐）

「设置」→ 底部「大模型答题设置」：

| 项目 | 说明 |
| --- | --- |
| 启用大模型答题 | 勾选后生效 |
| 答题策略 | `llm_first` 大模型优先、失败再查题库；`llm_only` 只用大模型；`tiku_first` 题库优先；`tiku_only` 只用题库 |
| 接口地址 | OpenAI 兼容接口，例如 `https://api.deepseek.com`（脚本会自动补 `/chat/completions`） |
| API 密钥 | 你自己申请的密钥 |
| 模型名称 | 例如 `deepseek-chat`、`qwen-plus`、`glm-4-plus`；也可以点下面的「从接口获取模型列表」，脚本会请求该接口地址的 `/models`，把可用模型放进下拉框，选中即填好 |
| 温度 | `0~2`，越低回答越稳定、越保守；答题建议 `0~0.3`。DeepSeek V4 系列默认开思考模式，思考模式下这个参数不生效 |
| 超时时间，单位秒 | 默认 60，网络慢可以调大 |
| 最大输出 token | 默认 `0`，表示不传这个参数、交给接口自己的默认上限（DeepSeek 思考模式默认 64K）。日志里出现「输出被截断」就把它设为 `0` 或调大 |

填好后点「测试大模型连接」，「首页」日志会给出结果；页面加载时也会打印一行 `大模型答题已就绪`，说明配置已被读取。

作答完成后，「题目」页的答案列和「首页」日志都会给出明确答案：单选题形如 `B. 上海`，多选题形如 `A. 北京、C. 广州`，判断题形如 `对`。模型怎么回答都能识别——只给字母、给「答案是B」、甚至直接把选项内容写出来，脚本都会换算成对应的选项。


### 题库（可选，需自备）

**本脚本不提供题库，也不推荐任何题库服务商**，请自行准备。若你已有自己的题库接口，在「答题」页填入接口地址和密钥即可；没有就留空，只用大模型答题。

自有题库需要实现以下接口：

- 请求：`POST {地址}/api/open/v1/search/exact`
- 请求体：`{"stem": "题干", "options": ["选项1", "选项2"], "type": "0"}`
- 返回：`{"success": true, "data": {"items": [{"stem": "题干", "answer": {"values": ["答案"]}}]}, "error": null, "meta": null}`
- 密钥：放在 `X-Consumer-Token` 请求头里
- 脚本会附带 `?s=作者&v=版本号` 查询参数，服务端忽略即可

## 常见问题

> 更完整的报错对照表在 [使用教程 · 常见报错对照表](./使用教程.md#六常见报错对照表)。

- 日志里没有 `大模型答题已就绪`：说明接口地址 / API 密钥 / 模型名称没填全，去「设置」补齐后刷新页面。
- 提示 `GM_xmlhttpRequest 不可用`：脚本管理器没有授予跨域权限，重新安装脚本并同意授权。
- 答案来源显示「剩余次数」：说明这一题走的是题库而不是大模型，检查「答题策略」。
- 请不要与其它同类脚本同时启用，会互相抢页面。
